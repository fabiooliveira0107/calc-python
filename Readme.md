# 🧮 Calculadora Simples em Python

Um projeto desenvolvido para praticar **lógica de programação** em Python, aplicando conceitos fundamentais como modularização de funções, estruturas de repetição, tratamento de exceções e validação de dados de entrada.

## 🚀 Funcionalidades

- **Operações Básicas:** Adição, Subtração, Multiplicação e Divisão.
- **Validação de Entrada ('try-except'):** Impede que o programa quebre caso o usuário digite letras ou caracteres inválidos.
- **Tratamento de Exceções:** Evita erros críticos como a divisão por zero.
- **Menu Contínuo:** Permite realizar múltiplas operações em sequência sem precisar reiniciar o script.
